PRISMA

Explora la sintaxis, reglas y potencia del lenguaje PRISMA. Un estándar académico para la teoría de compiladores.

Referencia del Lenguaje

Estructura y Bloques

MODULOclass

Define el nombre y el inicio del programa.

VARIABLESfields

Bloque global para declarar identificadores.

PRINCIPALmain

Cuerpo principal de ejecución del código.

FUNCIONmethod

Declaración de subrutinas o métodos.

FIN-...}

Cierra bloques (MODULO, SI, PARA, etc.).

Tipos de Datos

ENTEROint

Números enteros de 32 bits.

DECIMALdouble

Números con punto flotante.

TEXTOString

Cadenas de caracteres alfanuméricos.

BOOLEANOboolean

Valores de verdad (V o F).

VACIOvoid

Indica ausencia de retorno en funciones.

Control de Flujo

SI / ENTONCESif

Evaluación condicional de expresiones.

SINOelse

Bloque alternativo si la condición es falsa.

PARAfor

Bucle de iteración controlada.

MIENTRASwhile

Bucle basado en una condición lógica.

RETORNAreturn

Devuelve un valor al llamador.

I/O y Lógica

IMPRIMEprintln

Muestra información en la consola.

LEERScanner

Captura entrada del usuario.

V / Ftrue/false

Literales para valores booleanos.

Y / O / NO&& || !

Operadores lógicos fundamentales.

Reglas de Oro

Identificadores

Todos los nombres de variables y funciones deben comenzar obligatoriamente con una letra minúscula o un guion bajo (_).

Alcance Global

En PRISMA no existe el alcance local. Todas las variables declaradas son accesibles desde cualquier punto del programa.

Tipado Estricto

No se permite la mezcla de tipos en operaciones sin una validación previa. Los tipos deben coincidir exactamente.

Cierre de Bloques

Cada estructura (SI, MIENTRAS, PARA) debe cerrarse explícitamente con su etiqueta FIN- correspondiente.

Ejemplos Prácticos

Serie de Fibonacci

Implementación clásica utilizando ciclos y variables globales.

MODULO Fibonacci
VARIABLES
    ENTERO a = 0
    ENTERO b = 1
    ENTERO temp = 0
FIN-VARIABLES

PRINCIPAL
    MIENTRAS (a < 100)
        IMPRIME(a)
        temp = a + b
        a = b
        b = temp
    FIN-MIENTRAS
FIN-PRINCIPAL
FIN-MODULO
